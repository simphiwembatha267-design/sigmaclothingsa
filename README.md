# Sigma Brand Launch

Create a modern, high-end clothing brand website for a brand called Sigma.
The brand aesthetic is minimal, avant-garde, streetwear luxury.
Target audience: [18-31 years, street culture, mogul lifestyle.
The website should feel [emotion: exclusive, raw, poetic, rebellious, calm, bold].
Pages needed: Home, Shop, Product Page, About, Lookbook, Contact.
Design requirements:
– Clean typography
– Strong visual hierarchy
– Editorial / fashion-house feel
– Mobile-first and fast loading
Functionality:
– Product listings
– Cart & checkout
– Size guide
– Instagram integration
Use black & white as the base with subtle accents.
Make it feel like a global fashion brand (Tokyo, Paris, London energy).
